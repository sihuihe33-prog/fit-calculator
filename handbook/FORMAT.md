# 设计手册内容格式

每章一个文件：`handbook/NN-<id>.js`，**纯数据，不 import 任何东西**，默认导出一个章节对象。
页面脚本 `handbook-app.js` 负责渲染；`test/handbook.test.mjs` 会检查格式，提交前务必 `npm test` / `node --test "test/*.test.mjs"` 通过。

## 章节对象

```js
export default {
  id: 'gear',                 // 章节 id，小写英文，全站唯一；就是地址里 #gear/... 的前半段
  no: 3,                      // 章号
  title: '齿轮传动',
  sections: [
    {
      id: 'material',         // 节 id，小写英文和连字符，本章内唯一；地址为 handbook#gear/material
      title: '常用齿轮材料及其力学性能',
      keywords: ['调质', '淬火', '45钢', '40Cr'],  // 可选：搜索用的同义词/常见叫法
      src: ['濮良贵《机械设计》第十版 表10-1', 'GB/T 3077—2015'],  // 必填：数据/方法出处，至少一条
      body: [ /* 内容块，见下 */ ],
    },
  ],
};
```

## 内容块（body 数组里的元素）

字符串里允许少量内联 HTML：`<b> <i> <sub> <sup> <br> <code>`，以及站内链接
`<a href="#shaft/material">轴的常用材料</a>`（跳到手册其他节）。不要写别的标签，不要写 style。

| 写法 | 显示成 |
|---|---|
| `'一段文字'` | 段落 |
| `{ h: '小标题' }` | 节内小标题 |
| `{ ul: ['…', '…'] }` / `{ ol: [...] }` | 无序 / 有序列表 |
| `{ table: {...} }` | 数据表，见下 |
| `{ eq: 'T = 9550 P / n', no: '(1-3)', where: 'T——转矩，N·m；P——功率，kW；n——转速，r/min' }` | 居中公式，`no`、`where` 可选 |
| `{ note: '…', kind: 'tip' }` | 提示框；`kind` 为 `tip`（默认，蓝）或 `warn`（黄，用于易错点） |
| `{ fig: '<svg viewBox="…">…</svg>', caption: '图 1-1 …' }` | 简图，见下 |
| `{ tool: 'gear', text: '用「齿轮参数」计算器算几何尺寸' }` | 跳转到计算器的卡片；`tool` 取 site.js 里 TOOLS 的 id：fit bolt gear shaft bearing key units |

### 表格

```js
{ table: {
  caption: '表 3-2 常用齿轮材料',          // 必填
  head: ['材料', '热处理', '硬度', 'σ<sub>Hlim</sub>/MPa'],   // 一行表头；多行表头写成二维数组
  rows: [
    ['45', '调质', '217～255 HBW', '580'],
    [{ t: '40Cr', rs: 2 }, '调质', '241～286 HBW', '700'],   // rs 跨行，cs 跨列
    ['表面淬火', '48～55 HRC', '1150'],                       // 被上一行跨行占掉的格子不要再写
  ],
  note: '硬度范围取中值时可按线性插值估算。',               // 可选，表下注
} }
```

- 单元格可以是字符串、数字，或 `{ t, cs, rs }`。
- **每一行展开跨行跨列后列数必须等于表头列数**，测试会检查。
- 数值区间用全角波浪号「～」，负号用「−」或「-」都行，单位写在表头。

### 简图

- 只用内联 SVG，线条颜色写 `currentColor`，填充用 `none` 或 `currentColor` 加 `fill-opacity`，这样深色模式自动适配。
- 不加 width/height，只写 viewBox；字号用 `font-size="12"` 左右。
- 只画示意图（传动简图、结构示意），不要照描别家手册的插图。

## 写作要求

- 面向本科《机械设计》课程和减速器课程设计，**只讲用得到的**；每节先一两句说明「这是什么、什么时候用」，再给表和步骤。
- 文字用自己的话写，**不要照抄**任何手册或教材的原文段落；标准里的数值表可以照录，但必须核对。
- 数据拿不准的不写，或在 `note` 里写清楚「仅供课程设计参考，以现行标准为准」。
- 术语、符号与濮良贵《机械设计》（第十版）保持一致。
